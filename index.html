Nieuwe versie: verbind één keer opnieuw, zodat de app ook je playlists kan lezen.

Je hebt Spotify Premium nodig. De muziek speelt af in de Spotify-app op dit apparaat of op een speaker.

Hoe krijg ik een Client ID?
  1. Ga naar developer.spotify.com/dashboard en maak een app. Kies bij API's voor Web API.
  2. Zet bij Redirect URI precies dit adres:
  3. Kopieer het Client ID en plak het hieronder.

Spotify en de camera werken alleen via https://. Zet dit bestand dus bijvoorbeeld op Netlify Drop of GitHub Pages.

Afspelen

Dit geldt voor scannen en voor playlist spelen. Bij "Heel nummer" doet de tweede keuze niets.

Playlist spelen

De app schudt de nummers en speelt ze één voor één af. Alleen playlists van jezelf (of waarin je medewerker bent) kunnen gelezen worden. Een playlist van een ander kopieer je eerst naar een eigen playlist.
